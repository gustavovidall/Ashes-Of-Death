# Ashes of Death

Jogo 2D de ação e exploração inspirado em Dark Souls, com visual em pixel art, feito para rodar direto no navegador.

**Jogar online:** https://gustavovidall.github.io/Ashes-Of-Death/

## História

O reino do herói vivia em paz até que o rei maldito Valdrak destruiu tudo com seu exército de cinzas. Agora o guerreiro atravessa cinco regiões amaldiçoadas, enfrentando monstros e chefes, para acabar com a maldição e fazer seu reino descansar em paz.

## Recursos

- 5 zonas grandes, cada uma com vários monstros e um chefe no final
- 5 chefes, cada um com uma segunda fase
- Combate com combo de 3 golpes, golpe forte, esquiva, defesa e aparar no tempo certo
- Baús com itens aleatórios: comum, incomum, épico e lendário (mais raro e com muito mais dano)
- Inventário para trocar armas e armaduras
- Poções de vida e de vigor
- Barra de vida sobre os monstros e barra do chefe no topo da tela
- Fogueiras para subir de nível e salvar o progresso
- Menu completo: novo jogo, continuar, salvar, créditos e sair
- Cena de abertura, final com portal e paraíso, e créditos
- Salvamento automático no navegador

## Controles

| Tecla | Ação |
|---|---|
| A / D | Mover |
| W | Pular |
| S | Descer da plataforma |
| Shift | Esquivar |
| J | Ataque (combo de 3) |
| K | Golpe forte |
| L | Defender (no momento certo, apara) |
| Q | Poção de vida |
| R | Poção de vigor |
| E | Interagir (baús, fogueiras, portal) |
| I | Inventário |
| Esc | Menu / pausa |

O jogo também tem controles de toque para celular.

## Como rodar

Não precisa instalar nada. Abra o link acima, ou baixe o `index.html` e abra no navegador.

## Tecnologias

- HTML5 Canvas e JavaScript puro, em um único arquivo
- Gráficos em pixel art gerados por código
- Sons e música gerados com Web Audio API
- Progresso salvo em localStorage
